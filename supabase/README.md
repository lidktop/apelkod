# База данных

Тут лежит схема нашей базы (Supabase). Если вдруг понадобится поднять базу
заново (например, на другом аккаунте или для теста) — не надо вспоминать
всё руками, просто берём эти файлы.

Как накатить:
1. Заходим в Supabase → SQL Editor → New query
2. Вставляем содержимое `01_schema.sql`, жмём Run
3. Потом так же вставляем `02_addendum.sql`, жмём Run

Важно: перед первым файлом нужно один раз включить расширение `pg_cron`
(Database → Extensions → найти pg_cron → включить), иначе первый файл
упадёт с ошибкой на строке с напоминаниями.

Что где:
- `01_schema.sql` — основные таблицы (профили, предложения, сделки, чаты,
  уведомления) + кто что может делать (RLS)
- `02_addendum.sql` — то, что добавили позже: поля для каталога, демо-бизнесы,
  чтобы каталог не был пустой, и пара функций для автоподтверждения сделок

Ключи от Supabase (.env.local) сюда не кладём — они только у себя на
компьютере, в репозиторий не коммитятся. И service_role-ключ (secret) никому
не светим и никуда не вставляем — это полный доступ к базе в обход всех
проверок.
